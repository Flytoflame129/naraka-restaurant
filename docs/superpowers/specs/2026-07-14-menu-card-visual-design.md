# 菜单主题席签卡视觉设计

## 目标

在不增加图片、依赖和交互的前提下，增强 15 道菜单条目的主题辨识度、文字适配与视觉层级。菜单卡保持不可点击，不显示档案号、可信度或审核提示。

## 方案

采用“主题席签卡”方案。卡片继续使用现有 `MenuItemCard`，只增加主题标识和长标题状态，样式集中维护在 `src/styles/global.css`。

### 三个主题

- 聚窟洲：墨绿底、暗金边、低对比雾纹，整体温润克制。
- 火罗国：赤褐底、焦橙边、斜向热浪纹，整体明烈干燥。
- 龙隐洞天：曜黑紫底、冷青边、星盘放射纹，整体幽深冷峻。

所有纹理由 CSS 渐变生成，不新增图片资源。

### 卡片层级

卡片从上到下保持四层：

1. 席位编号与地图名。
2. 菜名。
3. 菜品描述。
4. 分类签牌。

分类签牌使用主题强调色、双线边框和小型侧饰，保持标签感但不表现为按钮。卡片不增加悬停位移、指针手势或其他可点击暗示。

### 长菜名

- 菜名达到 9 个汉字时添加 `is-long-title` 状态。
- 普通菜名使用当前标题层级的小幅收紧版本。
- 长菜名降低字号和行高，并使用均衡换行；移动端允许自然断行，不能裁切或溢出。

### 密度

- 移除固定的大面积最小高度，改为较小的稳定下限。
- 缩小卡片内边距与元素间距。
- 描述保持完整显示，不做行数截断。
- 同一行卡片由 CSS Grid 自动等高，分类签牌仍落在卡片底部。

## 文件范围

- `src/components/MenuItemCard.astro`
- `src/styles/global.css`

不修改菜单内容、schema、页面结构、图片资源或发布逻辑。

## 验证

- 运行 `npm.cmd run build`。
- 检查聚窟洲 8 道、火罗国 4 道、龙隐洞天 3 道均正常显示。
- 检查最长菜名在桌面双列和手机单列下无裁切、溢出或遮挡。
- 确认卡片没有链接、按钮、档案号、可信度和审核提示。
