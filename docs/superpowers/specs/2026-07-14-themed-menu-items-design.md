# 主题菜单条目设计

## 目标

将用户指定的 15 道虚拟菜品加入菜单页，并保证每道菜只在所属地图主题下显示。菜单条目属于本站原创餐厅设定，不自动视为已经完成来源考证的玩家梗档案。

## 内容边界

- 新建独立的 `MenuItem` 内容集合，与现有 `Dish` 集合分离。
- `MenuItem` 只承载菜单展示信息，不生成菜品详情页。
- 菜名由项目维护者明确指定，可以作为正式菜单名称展示。
- 简介只描述虚拟菜品的口味、摆盘或席面氛围，不擅自解释梗来源、角色关系、技能机制或社区传播历史。
- 已有 `Dish` 的来源审核、`status`、`publishStatus` 和公开详情页规则保持不变。

## 数据模型

每个菜单条目使用独立 Markdown 文件，frontmatter 包含：

- `title`：前端显示菜名。
- `slug`：稳定的英文或拼音 hyphen-case 标识。
- `map`：只能是 `聚窟洲`、`火罗国`、`龙隐洞天`。
- `category`：现有菜品分类之一。
- `description`：简短的本站原创菜单描述。
- `order`：同一主题内的显示顺序。

第一批数量固定为：聚窟洲 8 道、火罗国 4 道、龙隐洞天 3 道。

## 页面行为

- 菜单页进入时读取全局主题状态，默认使用 `聚窟洲`。
- 点击右上角主题按钮后，菜单页立即切换为对应主题，只显示该主题的菜单条目。
- 菜单页筛选按钮与右上角主题按钮共用 `juku`、`huoluo`、`longyin` 三个 key，并保持选中状态同步。
- 不提供“全部席位”，避免同时显示不同主题条目。
- 菜单条目卡片不可点击，不伪装成已有详情页的完整 Dish 卡片。
- 刷新页面后继续沿用保存在 `localStorage` 中的主题。

## 展示结构

- 当前地图主题标题与席面说明。
- 当前主题菜品数量。
- 菜单条目网格：菜名、分类、简短描述和地图标识。
- 沿用现有暗色武侠、金红边框、半透明面板和三主题 CSS Variables。

## 验证

- 内容 schema 能拒绝未知地图、重复或非法 slug、空标题和空简介。
- 三个主题分别只显示自己的 `8 / 4 / 3` 道菜。
- 右上角主题切换和菜单内主题按钮保持同步。
- 页面刷新后主题仍正确。
- 移动端卡片文字无溢出。
- `npm run validate:content` 通过。
- `npm run build` 通过。

## 非目标

- 本轮不新增菜品详情页。
- 不考证或解释这 15 个名称的梗来源。
- 不新增搜索、评论、登录、后端或大型依赖。
- 不修改项目 skills。
- 不推送远端仓库。
