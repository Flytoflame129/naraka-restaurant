# 内容研究模板

> 用途：研究《永劫无间》玩家梗、术语、社区表达或候选菜品来源。不要无来源编造；不确定的信息统一写“待考证”。

## 梗资料卡

- 梗名：
- 别名 / 常见写法：
- 可能原句：
- 相关角色：
- 相关武器：
- 相关地图：
- 相关操作：
- 梗类型：谐音梗 / 角色梗 / 武器梗 / 地图梗 / 操作梗 / 社区梗 / 赛事梗 / 二创梗 / 其他
- 来源平台：
- 来源链接：
- 证据摘录摘要：用自己的话概括证据，不大量复制原文。
- 可信度判断：高 / 中 / 低 / 待考证
- 是否适合菜品化：适合 / 仅适合待考证草稿 / 暂不建议
- 菜品化方向：
- 版权与风险备注：
- 待人工确认点：

## Source 字段草稿

```yaml
sources:
  - title: "来源标题"
    url: "https://example.com/source"
    platform: "平台"
    sourceType: "community"
    supports:
      - "这个来源具体支撑的说法"
    reliability: "medium"
    checkedAt: "2026-07-07"
    notes: "只支撑某些事实，不支撑页面里的二创吐槽或未核验结论。"
```
