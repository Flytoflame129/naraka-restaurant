# 视觉方向说明

## 当前问题

- 当前页面偏浅色餐厅官网，缺少《永劫无间 / NARAKA: BLADEPOINT》玩家同好项目的识别度。
- 卡片像普通外卖或餐厅菜品卡，游戏资讯卡、角色卡、活动卡的氛围不足。
- 首页 Hero 视觉区不够强，缺少暗色武侠、东方幻想、金红黑对比和仪式感标题。
- 地图主题命名过于泛化，不能准确承接项目语境和后续视觉设计。

## 新视觉目标

- 站点仍是“虚拟游戏主题餐厅”，但视觉语言改为游戏活动页 + 梗菜单站。
- 主氛围为暗色武侠 / 东方幻想：黑、红、暗金、古铜、冷青、雾白。
- 首页使用大面积 Hero 视觉区，强化标题、标语、主题入口和投稿入口。
- 卡片参考游戏官网资讯卡、活动卡、角色卡的节奏：大图、暗纹、边框、状态标签、半透明面板。
- 页面文案要像玩家梗食肆的情报板、菜单卷轴和后厨委托，而不是普通餐饮售卖。

## 官网参考点

可参考《永劫无间》官网的整体节奏和视觉语言：

- 首屏强调大标题、强氛围背景和主要行动按钮。
- 使用暗色底、红金强调色、半透明内容面板。
- 资讯、活动、角色等入口通常以图文卡片组织。
- 页面分区节奏清晰，视觉上有“游戏世界入口”的仪式感。

## 不允许复制的内容

- 不复制官网 Logo、游戏截图、角色图、宣传图、视频帧、UI 组件或文案。
- 不上传从游戏客户端直接提取的素材。
- 不冒充官方公告、官方活动、官方资料站或官方菜单。
- 不用未授权二创、截图、海报或社区图片作为站点正式素材。
- 如未来临时使用占位图，必须标明“临时占位，不可发布为正式素材”。

## 三个地图主题设计规范

### 聚窟洲

- 主题 key：`juku`
- 展示名：聚窟洲
- 氛围：雾气、古树、岛屿、江湖初入局。
- 色彩：深墨绿、暗金、温红、雾白。
- 适合菜品：经典玩家梗、老地图梗、入门梗。
- 页面语气：像初入江湖的菜单卷首，清晰但带一点开局仪式感。

### 火罗国

- 主题 key：`huoluo`
- 展示名：火罗国
- 氛围：烈日、沙海、古城、机关、异域宴席。
- 色彩：沙金、赤红、焦橙、深褐。
- 适合菜品：高温、爆炒、烈性、机关、沙漠相关梗。
- 页面语气：更热烈，适合“爆炒”“烈宴”“机关上菜”等表达。

### 龙隐洞天

- 主题 key：`longyin`
- 展示名：龙隐洞天
- 氛围：地宫、矿洞、龙纹、幽光、机关遗迹。
- 色彩：曜黑、熔岩红、冷青、古铜金。
- 适合菜品：地下、阴间、机关、翻盘、幽默怪菜梗。
- 页面语气：幽深、诡谲、带一点“怪菜”和反转感。
- 命名注意：统一写“龙隐洞天”，不要写成“龙影洞天”。

## 页面级改造清单

- 首页 `/`：改为游戏官网感首屏 Hero，使用“聚窟开席，劫味上桌”等仪式感标题；展示三个主题入口、今日招牌菜、玩家热梗和投稿入口。
- 菜单页 `/menu`：改为菜单卷轴 / 情报板 / 悬赏榜风格；支持按聚窟洲、火罗国、龙隐洞天筛选。
- 菜品详情页 `/dishes/[slug]`：顶部使用菜品 Hero 区；正文按菜品介绍、梗的来源、菜品设定、玩家吐槽、推荐搭配、来源链接、待考证说明组织。
- 投稿页 `/submit`：改为“向后厨递交新菜谱”的设定，明确梗名、出处、相关角色 / 武器 / 地图、图片授权和展示许可。
- 关于页 `/about`：强调非官方同好项目、玩家梗文化整理、虚拟餐厅包装和不代表官方立场。
